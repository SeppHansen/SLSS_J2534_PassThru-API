Installation Start:
Please start the installation only by running the setup.exe file.
The file SLSS_J2534_PassThru_Installer.msi only contains the installation content and must not be used directly to start the installation process.

Configuration Setup:
During installation, the configuration tool launches, allowing you to configure the default settings for the API functions. Configure ans save 
your desired settings to register the SeRoSys-CAN hardware with the PassThru API. The configuration program also allows you to test if the connection
to the dongle has been successfully established.

Using the Diagnostic Tool:
Once installation and configuration is complete, you can launch your diagnostic tool and select the SLSS J2534 PassThru API as the communication interface.

License Requirement:
Please note that a valid license is required to use the PassThru API.
Licenses can be purchased from SeRoSys Technology LLC.
